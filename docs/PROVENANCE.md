The baseline is frequentist and does not replace Bayesian posterior sampling. Figures 01–15 preserve embedded notebook plots; figures 16–24 show recomputed data, baseline evidence and actual source. A shared manifest and content renderer keep README and webpage aligned. The enhanced figure framing preserves plot aspect ratios and uses consistent high-contrast surfaces.

The data fingerprint is recorded in `reports/baseline_environment.json`. No standalone release files or duplicate repository ZIPs are required. Original academic material and the dataset have no supplied redistribution license; no new license is asserted on behalf of their owners.
