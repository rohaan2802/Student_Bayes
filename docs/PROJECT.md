# Project metadata

Name: `Student_Bayes`

Description: Bayesian student-performance modeling with reproducible evaluation, a runnable Python project, an interactive probability explorer, and 24 evidence figures.

Website: https://rohaan2802.github.io/Student_Bayes/

Topics: python, bayesian-statistics, pymc, statistical-modeling, regression, hierarchical-models, classification, data-visualization, student-performance, jupyter-notebook

The Python project is configured in `pyproject.toml`. `Student_Bayes.code-workspace` provides IDE tasks. The enhanced application is `src/analyze.py`; the full Bayesian study is `notebooks/student_models.ipynb`. No compiled executable or external release assets are required.
